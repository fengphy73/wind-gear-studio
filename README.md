# 風力齒輪設計室 · v1.3.1

繁體中文、手機與電腦皆可使用的單顆漸開線直齒外齒輪設計器。所有幾何運算及下載在瀏覽器完成，不需另外建立設計器帳號。

## 功能

- 預設：20 齒、模數 1、壓力角 20°、本體厚度 7.5 mm、圓孔直徑 5 mm。
- 20／60／80 齒起點；實心或肋條，調整外圈厚度與中央實心區。
- 圓孔與六角孔；六角以對邊距輸入。孔尺寸補償是整個直徑／對邊距的增加量。
- 輪轂關閉、A 面單側凸出、雙側凸出；外徑與兩端高度可調。
- 指定 A／B 面擋板；擋板厚度包含在原總厚度；背面小孔為 0 時完全封底。
- 止付螺絲攻牙底孔；孔數、直徑、圓周角度、距 A 面外端位置可調；列印後攻牙。
- 3D 旋轉、縮放、正反面、半剖檢視；WebGL 不可用時自動使用 Canvas 相容顯示。
- 2D 正投影與中心孔軸向剖面示意；顯示外徑、節圓、孔尺寸、總厚與插入深度。
- 文字標記：凸字與凹字、固定粗黑體、常用中文／英文／數字；可選 A／B 面本體或輪轂端面，調整實際字高、XY 位置、旋轉、刻深／凸高。文字以實體布林運算輸出，非預覽貼圖。
- 二進位 STL（mm）；版本化 JSON 設定下載及匯入，白名單欄位與參數檢查。

## 尺寸定義

齒輪本體由 B 側輪轂頂端起算；A 面為 +Z 外端，B 面為 Z=0。總厚度＝本體厚度＋A 面凸出高度＋B 面凸出高度。輪轂及本體為布林聯集，軸孔、減重窗、退出孔及徑向攻牙底孔為布林差集。

背面擋板由該端外表面向內佔用厚度。可插入深度＝總厚度−擋板厚度。止付孔距 A 面量起，並檢查孔邊及封底位置。減重模式中央實心區外徑與輪轂共用。

## 建置與驗證

`npm ci` → `npm test` → `npm run build`。靜態輸出位於 `dist/`，包含 WASM，沒有執行時 CDN 依賴。瀏覽器需要支援 WebAssembly、Web Worker 與 Canvas。STL 用完整模型；半剖只影響畫面。

十組幾何案例檢查單一實體、網格每邊恰有兩個反向面、厚度與界限、擋板厚度、中心通孔、設定往返及 STL 格式；另測錯誤參數拒絕。測試輸出不進版控。

## 第一版界限

齒面為漸開線，齒根為簡化的徑向／圓弧過渡，未實作滾齒生成的擺線與完整根切模擬。少齒數及變位可能有干涉，畫面會提示。單顆設計不驗證配對齒輪的嚙合、強度或負載能力。最小厚度檢查是保守的幾何門檻，不是材料強度認證。正式使用前試印並檢查配合。

曲線以分段近似；圓孔 96 段，六角孔精確六邊形。2D 的中心孔軸向剖面是示意，不包含徑向止付孔；3D 與 STL 顯示實際布林模型。模型體積不是切片耗材預估。

## v1.1 文字規則

字高依整段文字的可見輪廓高度計算，文字以可見輪廓的中心定位。XY 與旋轉由所選面正視定義；B 面會反轉模型 X，使實體從背面觀看時文字正常可讀。文字限一行 1–20 字，不支援的字元會明確拒絕，不會輸出缺字框。

字形全域須落在該面實際露出的實心區內，距孔洞、減重窗與邊界至少 0.2 mm，並限制在齒根圓內。不可放在凸出輪轂遮住的本體表面。凹字以完整字形柱體檢查刻深及其下 0.6 mm 材料，避免刻穿、侵入軸孔／止付孔；凸字須完整連接表面。

字型首次啟用才載入約 8.3 MB。Gear Label TC Bold 是 Noto Sans CJK TC Bold 的改名子集，附完整 OFL 授權與來源於 assets/FONT-LICENSE.txt，建置時一併輸出。包含常用漢字、英文、數字、全形符號與注音；不包含 emoji 或全部罕用字。只提供此款字型，未提供任意字型上傳或曲線排字。

設定檔輸出為 v2，仍可匯入 v1，新增文字欄位會補上預設關閉。模型總厚會包含超出原本外表面的凸字；中心孔插入深度仍按原本本體／輪轂／擋板計算。

文字測試另外驗證 12 組中英文、正反面、凸凹字、輪轂、肋條及封底案例的體積變化與 STL 封閉性，7 組無材料／碰孔／刻穿／不支援字元的拒絕案例，並驗證舊設定相容與預覽座標方向。

## v1.2 自動安排與文字錯誤預覽

新增自動／手動位置模式。新文字預設自動，以目標字高為上限，依序測試原位置、中央實心區、肋條及外圈；同一字高的候選位置全部嘗試後才縮小。通常不低於 1.2 mm，使用者明確設定更小字高時以其設定為下限。不改齒輪幾何、不跨到另一標記面、不使用曲線排字；自動搜尋仍可能無解。

配置以字型的實際輪廓與當前露出面進行布林差集，並檢查凹字下方材料。背面使用反向座標、肋條文字沿肋條方向排列。畫面顯示實際配置區域、字高、XY 及角度；切換手動時接續這些實際值。

文字錯誤不再清空或模糊齒輪。Worker 回傳當前齒輪本體及獨立文字錯誤；2D 用紅色輪廓提示未加入模型的文字。錯誤期間停用 STL，底層 binarySTL 也會拒絕不完整結果，不能靜默略過文字。使用者可選擇自動安排、手動修正或明確關閉文字後輸出。字型載入失敗時也保留本體預覽。

設定檔升為 v3，繼續接受 v1／v2；舊設定保留手動位置，按「自動安排文字」即可轉換。測試包含用戶截圖的 100 齒、六角孔 5 mm、四肋條 5 mm、外圈 3 mm、中央實心區 12 mm 案例，保持 2.5 mm 字高自動移至肋條。

## v1.3 數字輸入恢復

數字欄位改用獨立文字草稿，與模型的有限數字參數分開。有效數字才更新模型；空白、負號、未完成小數／指數、錯字不會寫入 NaN。可接受欄位對應單位（例如 6.3 mm、毫米、公釐）、全形數字與小數逗號，失焦後正規化為純數字；不使用 parseFloat 截斷錯誤字串。

未完成輸入會在欄位旁提示並停用 STL，保留已確認數值的預覽；「復原此欄」與 Escape 可取消草稿。鍵盤上下鍵保留步進功能。預設、匯入及恢復參數時同步清理全部欄位草稿。

新增「恢復上次可用設定」，使用當前頁面最近一次完整成功生成的參數；不會把文字失敗後的暫時本體當成完整成功模型。幾何錯誤時保留前一模型並清楚標記為舊預覽，不再模糊整個畫面。恢復紀錄目前限當前頁面，重新整理前仍建議保存設定。

新增輸入解析、錯誤到有效值轉換、單位與全形處理、100 齒六角對邊 6.3 mm 的測試；瀏覽器另實測錯字、清空、全形數字、單欄復原與範圍錯誤後整體復原。

## v1.3.1 擋板預設

擋板預設厚度改為 0.5 mm，對應驗證下限同步調整為 0.5 mm。匯入既有設定時保留檔案中的明確厚度。測試檢查 0.5 mm 封底的實際厚度、STL 封閉性及 0.49 mm 拒絕；刻字保留材料的檢查維持獨立。
